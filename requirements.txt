# 1. Check if the Container is Running
# First, check the status of your container to see if it's already running:
# code
# Bash
# docker ps
# If you see local-mongo listed with a status like Up ..., it's running, and you can skip to the connection command.
# If it's not listed, it means it was stopped (or removed).
# 2. Start the Existing Container
# If the container is stopped, use the start command to resume it:
# code
# Bash
# docker start local-mongo
# 3. Connect to MongoDB Shell (Reuse Connection)
# Once you confirm it's running (or after running docker start), you can connect to the MongoDB shell inside the running container using the exec command you used before. Make sure you are running this in your regular command prompt/terminal, not inside the MongoDB shell itself.
# code
# Bash
# docker exec -it local-mongo mongosh
# Important Note on Credentials:
# When you connect using the command above, you will likely be prompted for authentication because you set the root user/password when you first created it:
# Username: mongoadmin
# Password: secret
# Summary of Commands for Reusing:
# Start the container:
# code
# Bash
# docker start local-mongo
# Connect to the shell (optional, for testing/admin):
# code
# Bash
# docker exec -it local-mongo mongosh
# Your data will be preserved because you mapped no volumes, meaning the data is stored in the container's writable layer, which persists until you explicitly remove the container with docker rm.
